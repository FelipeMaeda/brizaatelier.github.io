# Briza Atelier — site estático

Site responsivo pronto para GitHub Pages.

## Antes de publicar

1. Coloque sua logo em `assets/images/logo.png` (preferencialmente PNG transparente).
2. Em `js/script.js`, troque `5521999999999` pelo WhatsApp da empresa, com DDI e DDD, apenas números.
3. Em `index.html`, ajuste e-mail, Instagram, Pinterest, cidade e textos de produtos.
4. Se quiser domínio próprio, crie um arquivo `CNAME` na raiz contendo apenas: `brizaatelier.com.br`.

## Publicação no GitHub Pages

1. Crie um repositório público, por exemplo `brizaatelier`.
2. Envie todo o conteúdo desta pasta para a raiz do repositório.
3. Abra **Settings > Pages**.
4. Em **Build and deployment**, selecione **Deploy from a branch**.
5. Escolha a branch `main` e a pasta `/ (root)`, depois salve.

O endereço inicial ficará parecido com `https://seuusuario.github.io/brizaatelier/`.
